## 下载与运行

- 安装版运行 `Qilu-Setup-0.4.2rc1-x64.exe`，包含卸载程序。
- 便携版完整解压 `Qilu-0.4.2-rc.1-x64.zip`，再运行绮录。
- 安装版和便携版均自带运行库。

## 问题修复

- 安装器为绮录的程序目录补齐沙箱启动所需的读取权限。
- HTML 长会话导出自动分片并保留 `chat.html` 入口。大体量 PDF 在达到保护上限时给出提示，其余已选格式可以继续导出。
- 减少分页时的重复消息解析，并在导出报告中统计未能写入的消息。

## 支持的系统范围

- Windows 11 x64 为候选构建的验证目标。Windows 10 x64 兼容性待本版本复验。
