# 绮录QQ聊天记录导出软件 P3+ 项目书

**审阅稿 · 2026-11-19**

## 阶段目标

以 P3 的 `0.4.2rc1` 为基线，补齐发布验收，集中修复已有功能中的稳定性和兼容性问题。该候选版已通过 Windows 11 x64 安装、便携、卸载及合成归档三格式导出。Windows 10、真实 QQ 数据和正式性能验收仍待复验。[P3 项目书](2026-11-19-p3-release-quality.md)

## 实施约束

- 现有布局、样式、组件和交互按原基线验收。确需改 UI 时，以用户明确要求为准，先在仓库和构建清理目录之外保存原档，登记提交号、未提交差异、原路径及恢复步骤。[项目协作原则](../../../AGENTS.md)
- 自动测试离屏运行。需要可见窗口的性能测试放在独立测试桌面或虚拟机。合成测试使用隔离配置。真实 QQ 验收经本人授权，按客户端的自然运行或退出状态记录，只读访问源数据。
- 构建、缓存和验收产物集中在项目目录。真实会话、密钥、个人路径和商店配置留在本机。逐任务提交，版本号随已批准的发布范围调整。[版本规则](../../VERSIONING.md)

## 任务与验收

| 任务 | 工作内容 | 验收条件 |
| --- | --- | --- |
| T01 建立性能基线 | 在固定机器上，用 10 万条会话和混合媒体测量冷／热打开、切换账号、连续滚轮、随机跳转、冷缩略图和搜索。记录渲染、IPC、查询与解析各自耗时。 | 每项至少五轮，输出 P50、P95、峰值内存及环境。沿用首屏 ≤300 ms、前台滚动 ≥55 FPS、冷缩略图 ≤200 ms 作为初始目标。离屏数据用于功能回归。 |
| T02 优化已定位的瓶颈 | 检查过期分页、后台刷新与当前会话争用、首屏媒体任务优先级。有实测收益时再调整并发、缓存与预取。 | 同设备同样本对照，主指标改善且资源开销有记录。快速切换与跳转后仍保持正确账号、会话、排序、勾选和滚动锚点。 |
| T03 故障检测与修复 | 用合成数据注入磁盘写满、附件复制中断、文件被占用、导出取消、重复发起、快照繁忙及归档损坏。复核分片链接、PDF 超限、报告计数和恢复队列。 | 有复现的缺陷对应回归用例。旧产物仍可读取。任务完成、失败或取消后清理临时文件，重试无重复或半成品。 |
| T04 兼容与离线验收 | 在 Windows 10 22H2 x64 和 Windows 11 x64 验证同构建的安装、便携、卸载与离线导出。用授权样本核对 QQ 运行、退出及账户历史数据可用条件。 | 逐项记录系统构建号、包哈希和通过状态。真实样本验收证明账号隔离、最近消息与源数据只读。报告仅保留脱敏证据。 |

## 交付与版本

先完成复现和基线，再提交性能改动与修复，最后固定同一构建进行系统验收。交付缺陷清单、性能对照、兼容矩阵、安装包、便携包和哈希。当前候选如需修订，递增 `rcN`。本阶段拟以 `0.4.2` 正式版收口，前提是拟声明范围通过验收。后续独立维护补丁按第三段递增。
